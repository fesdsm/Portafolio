📦 Proyectos ETL

Este directorio reúne una colección de proyectos ETL desarrollados como parte de mi proceso de aprendizaje y consolidación en el área de datos. Cada proyecto está orientado a la práctica de extracción, transformación y carga de datos, replicando flujos de trabajo utilizados en entornos profesionales.

Los proyectos abordan distintos escenarios y problemáticas, incluyendo limpieza de datos, transformaciones, validaciones, cargas incrementales y diseño de modelos de datos, utilizando principalmente SQL y bases de datos relacionales.

Los procesos se desarrollan sobre conjuntos de datos simulados o ficticios, diseñados para representar situaciones reales, con énfasis en la calidad de los datos, la eficiencia de las cargas y la correcta estructuración del modelo destino.

Este repositorio forma parte de mi portafolio personal y tiene como objetivo documentar mi progreso en el diseño e implementación de procesos ETL, así como demostrar mi capacidad para estructurar y mantener pipelines de datos claros, reproducibles y bien documentados.
