📊 Excel - Proyectos de Análisis y Gestión de Datos  

Esta carpeta reúne los proyectos que he desarrollado utilizando **Microsoft Excel**, con el objetivo de organizar, analizar y comunicar información de manera efectiva. Los trabajos documentan la aplicación práctica de conceptos de análisis de datos dentro de un flujo profesional.  

📂 Contenido  

Los proyectos incluidos en esta carpeta están orientados a:  

- 🧹 **Limpieza y transformación de datos**: uso de funciones, tablas y herramientas de validación.  
- 📑 **Modelado estructurado**: creación de tablas dinámicas, rangos estructurados y normalización de datos.  
- 📈 **Visualización de información**: gráficos dinámicos, segmentaciones y dashboards interactivos.  
- ➗ **Cálculos avanzados**: fórmulas complejas, funciones anidadas y KPIs en Excel.  
- ⏳ **Análisis temporal y tendencias**: manejo de fechas, series de tiempo y proyecciones.  
- 📖 **Documentación y storytelling**: explicación clara de resultados y construcción de reportes ejecutivos.  

Los datasets utilizados son reales o simulados y permiten explorar distintos escenarios de negocio, como ventas, inventarios, clientes y categorías, según corresponda a cada proyecto.  

🎯 Objetivo  

Esta carpeta tiene como objetivo demostrar:  

- Resolución de problemas de análisis de datos mediante **Excel**.  
- Aplicación de **Power Query** para limpieza, transformación y consolidación de datos.  
- Uso de **tablas dinámicas, segmentaciones y gráficos** para dashboards interactivos.  
- Dominio de **funciones avanzadas** (BUSCARX, SUMAR.SI.CONJUNTO, LAMBDA, etc.).  
- Capacidad para documentar proyectos de manera clara, profesional y replicable.  

🛠️ Herramientas  

- 📊 **Microsoft Excel**: análisis, modelado y visualización de datos.  
- 🔄 **Power Query**: transformación y automatización de procesos de carga de datos.  
- 🔗 **Conexiones externas**: archivos CSV, bases de datos y fuentes en la nube.  
- 📝 **Markdown**: documentación de los proyectos.  

Cada proyecto dentro de esta carpeta incluye una descripción del objetivo, los reportes creados, las fórmulas y herramientas aplicadas, y los hallazgos obtenidos, permitiendo replicar y comprender el análisis de manera autónoma.
